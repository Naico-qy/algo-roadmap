# 机试训练路线图

面向**保研夏令营 / 预推免机试**的 C++ 训练站：不自己出题判题，而是把成熟平台的题目按
**科学顺序**组织成 30 周路线，并记录你的进度、笔记与复盘。

- 打开方式：`python serve.py`，然后访问 <http://127.0.0.1:8900/>
- 所有练习一键跳转到各平台官方页面（力扣 / 洛谷 / 牛客 / AcWing / 头歌 / PTA / AtCoder…）
- 进度、笔记、复盘存在浏览器 localStorage，可导出 JSON 备份

---

## 先回答：你的学习顺序科学吗？

**主干是对的**：基础语法 → 基础数据结构 → 算法 → 大规模训练。但按学习科学的证据，有 3 处应该修正
（站内「今日」页有完整 7 条，这里说最关键的）：

1. **不要做成四段割裂的直线**。学完语法就不再碰语法、学完数据结构就把栈队列忘掉，是最常见的失效方式。
   每个阶段要留 20–30% 时间做前面内容的**混合复习**。
2. **语法阶段不要超过 3 周**。你已有编程基础的话，C++ 语法应该在"用"中补，从"背"里学效率很低。
3. **块状练习会制造虚假熟练**。同一类题连做 20 道会觉得自己会了，但那是题目在提示你用哪个方法。
   真实机试没人给你这个线索——所以每个阶段末要混合题单，第 8 周起每周限时模拟。

另外两条决定成败：**难度控制在 60–75% 通过率**（太简单是重复劳动，太难是无效挣扎）；
**复盘的价值不低于刷题量**（错题按 1/3/7/21/45 天重做，本站自动排期）。

## 路线结构（30 周）

| 阶段 | 周期 | 内容 | 通关标准 |
|---|---|---|---|
| S0 环境与手感 | 第 1 周 | 编译/调试/对拍/OJ 习惯 | 5 分钟跑通「读入→处理→输出」，会写对拍 |
| S1 C++ 语法与 STL | 2–4 周 | 类型溢出、字符串、结构体排序、STL 全家桶、二分查找 | 30 分钟写出「读入→排序→去重→输出」不查文档 |
| S2 基础数据结构 | 5–8 周 | 前缀和/差分、双指针、单调栈、哈希、堆、树、并查集、图存储 | 60 分钟独立完成中等结构题并说清选型理由 |
| S3 基础算法 | 9–14 周 | 二分、贪心、DFS/BFS、回溯、DP、字符串、数论 | 40 分钟 AC 一道随机中等题，能口述 DP 四步 |
| S4 进阶专题（选学） | 15–21 周 | 最短路、MST、树状数组、线段树、LCA、树形/状压 DP、Trie | 30 分钟默写 Dijkstra/并查集/线段树模板 |
| S5 限时模拟 | 22–30 周 | 限时策略、部分分、对拍、错因归档、周赛 | 连续 4 周每周 ≥2 场模拟并完成补题 |

> **S4 是「按目标院校选学」**：先看目标院校近 3 年真题的水位再决定投入。多数保研机试在
> 「洛谷普及- ~ 提高-」之间，只有少数 Top 院校会到提高+/省选。不要为了安全感无限扩张专题。

每个阶段都写清了：**为什么放在这个位置**、知识点清单（可勾选 + 记笔记）、配套练习（可填已完成题数）、
**通关标准**、以及**这一阶段最容易踩的坑**。

## AI 侧栏（边学边问）

页面右下角的「AI」按钮打开右侧栏，聊天记录、题目上下文都在这一条侧栏里完成。

### 为什么不是直接嵌 DeepSeek 网页版

不是不想，是不成立：`chat.deepseek.com` 与本站在不同源，就算能塞进 iframe，父页面对它既
**读不到回答**也**注入不了问题**（浏览器同源策略）。你等于要在两个框里各打一遍字，比复制粘贴更麻烦。
所以网页版做成了「一键复制问题 + 打开网页」，一次粘贴即可。

### 三种用法，按需选

| 方式 | 费用 | 需要什么 | 适合 |
|---|---|---|---|
| **网页版兜底** | 免费 | 无 | 不想配任何东西；偶尔问 |
| **API 直连**（推荐） | 按 token 计费，单价低 | 一个 Key，填在侧栏里 | 高频问、要上下文自动带上 |
| **本地 Ollama** | 免费、不联网 | 本机装 Ollama 并 pull 模型 | 有显卡/内存，在意隐私 |

服务商已内置：DeepSeek、智谱 GLM、Kimi、硅基流动、本地 Ollama，以及**演示通道**（不联网、
只回固定文字，用来确认侧栏和流式渲染正常、零费用）。

> 具体价格与免费额度各平台会调整，以官网为准。日常问答的量级通常很便宜，但不做承诺。

### 配置

打开侧栏 → 右上角 ⚙ → 选服务商 → 填 Key → 保存并启用。立即生效，不用重启服务。

Key 存在 `serve.py` 同目录的 `config.json`（权限 600），**不进入浏览器 localStorage**，
也不会被「导出进度备份」带走。清空配置用同一面板的「清除配置」。

也可以用环境变量 `DEEPSEEK_API_KEY`（仅在未保存过 Key 时生效）。注意：程序**只认与所选服务商
匹配的环境变量**，不会把你机器上别的厂商 Key 转发出去。

### 上下文注入

知识点、练习、错题卡片旁都有「问」按钮：点一下会把该条目的阶段/要点/链接作为【背景】连同你的
问题一起发给模型（气泡里只显示你问的那句话，不刷屏）。也可以直接打字问，默认不带上下文。

### 接口（自己接别的模型）

`serve.py` 顺带提供了三个本地接口，都是同源、只监听 `127.0.0.1`：

- `GET  /api/status` — 当前配置状态（不回传 Key 明文）
- `POST /api/config` — 保存/清除 provider、apiKey、model、baseUrl
- `POST /api/chat` — SSE 流式转发到上游（OpenAI 兼容格式）

任何 OpenAI 兼容端点都能接：把 `baseUrl` 指过去、`model` 填对即可。

## 站点功能

- **今日**：只做三件事——① 新知识点 ② 到期复盘 ③ 混合练习。附倒计时与「进度正常/落后几周」。
- **路线图**：六个阶段的完整清单，知识点打勾记进度，题单填已完成题数（Enter 或失焦即保存）。
- **复盘本**：记错题（题目 + 错因分类 + 一句话教训），自动按 **1/3/7/21/45 天**排复习；
  「重做成功」升档，「还是不会」重置到 1 天。带错因分布统计。
- **资源库**：19 个平台/资源，标注「适合什么」和「要注意什么」（含哪些国内访问可能不稳），可按类型/难度筛选。
- **进度**：整体完成度、知识点数、刷题数、复盘数、连续天数、计划周vs实际周、14 天活动热力。
- **设置**：改目标考试日期、每日任务量、导出/导入备份、清空。

## 怎么用

```bash
cd algo-roadmap
python serve.py          # 默认 8900，可传端口：python serve.py 8080
```

1. 第一次打开先去「设置」把**目标考试日期**改成你的实际机试日期（默认 2027-06-15，按夏令营窗口倒排）。
2. 每天只打开「今日」，按 ①②③ 顺序做，不要跳。
3. 做完就打勾 / 填题数——进度和周次对照全靠它。
4. 做错的题立刻记一条，30 秒就够；到期那天不看题解重做。

> 直接双击 `index.html` 打不开数据（浏览器会拦截本地 `fetch`），必须用 `serve.py`
> 或任意静态服务器（`python -m http.server`）。

## 数据与备份

- 存储位置：浏览器 `localStorage`，键名 `algo-roadmap.v1`。
- 换设备 / 清缓存前，在「设置 → 导出 JSON」备份；新设备「导入 JSON」恢复。
- 同一台电脑换浏览器（Chrome ↔ Edge）数据不共享。

## 边界说明

- 本站**不判题**，题解、评测、难度体系都由各平台提供；本站负责"顺序、记录、复盘"。
- 外链均为各平台官网；Codeforces / cses.fi 在国内可能需代理，已在资源卡里标注。
- AI 的回答可能出错，尤其是题解细节与复杂度；它的定位是「随时能问的助教」，不是判题机。
- 学习科学层面的建议是通用规律，不替代你对自己水平和目标院校真题水位的判断。

## 云同步（可选）：进度存在哪

本站没有服务器，所以数据分三类存放：

| 数据 | 存哪 | 说明 |
|---|---|---|
| 课程内容 `curriculum.json` | 仓库 | 静态资源，随页面一起部署 |
| **学习进度 / 笔记 / 复盘** | **浏览器 localStorage** | 默认只在本机；可开启 Gist 同步 |
| AI API Key | 浏览器 localStorage | 不上传、不进备份 |

### 开启跨设备同步（GitHub Gist）

1. GitHub → Settings → Developer settings → **Fine-grained token**，只勾 **Gists: Read and write**
2. 站内「设置 → 云同步」填入 token，点「保存并上传」——会自动创建一个 **secret gist**
3. 另一台设备填同一个 token + Gist ID，点「从云端恢复」
4. 打开「自动同步」后，每次改动约 2 秒后自动上传（防抖）

同步内容：知识点完成状态、题单题数、笔记、复盘卡片与复习排期、每日活动、时间戳。
**不含** API Key。

冲突处理：启动时若云端 `updatedAt` 更新，会提示「云端记录比本机新」，由你决定是否覆盖，
不会自动覆盖。secret gist 有修订历史，可在 GitHub 上回滚。

> **安全边界**：secret gist 只是"不被公开列出"，**拿到链接的人仍可读取**；
> token 存在本机浏览器，公用电脑不要开启。想真正私有请用私有仓库或带账号体系的服务。

更完整的存储决策与部署说明见本地工作区文档《存储方案.md》《部署与启动说明.md》。
